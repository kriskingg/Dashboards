# D01 — NIFTY Paper Research Dashboard

## What this is

D01 is the NIFTY options paper/shadow research dashboard. It displays forward-paper signals, trades, P&L, strategy comparison, filters, evidence quality and research analytics.

This dashboard is **paper/shadow only**. It must not be treated as a live broker execution surface.

## End-to-end runtime path

```text
Browser
  -> Cloudflare Quick Tunnel
  -> chartink-paper:127.0.0.1:8765
  -> nifty-multi-shadow-dashboard.service
  -> mcx_paper.control_server
  -> /var/lib/chartink-paper/nifty-multi-shadow/reports/live_latest.html
```

The HTTP server only serves the generated page. It is **not** the NIFTY strategy/dashboard generator.

## If you want to change this dashboard

### Presentation / HTML / charts / filters

Edit:

```text
nifty-options-paper-research/analysis/nifty_multi_shadow/dashboard.py
```

This is the main file for:

- page layout;
- cards/tables;
- JavaScript embedded in generated HTML;
- charts;
- filters;
- strategy labels;
- evidence presentation;
- aggregate analytics.

### Data/state passed into the page

Edit:

```text
nifty-options-paper-research/analysis/nifty_multi_shadow/live.py
```

### Browser refresh policy

Edit:

```text
nifty-options-paper-research/analysis/nifty_multi_shadow/dashboard_refresh.py
```

### Strategy logic

Do **not** change dashboard code when the requested change is actually a strategy/formula/risk change.

Strategy logic belongs to the NIFTY engine modules under:

```text
nifty-options-paper-research/analysis/nifty_multi_shadow/
```

including the engine, statistical basket and strategy-specific modules.

### Never edit directly

Do not make permanent changes to:

```text
/var/lib/chartink-paper/nifty-multi-shadow/reports/live_latest.html
```

It is generated output.

## Required tests

Minimum dashboard regression:

```text
nifty-options-paper-research/analysis/test_nifty_dashboard_v2.py
```

If a change touches strategy/state generation, run the full NIFTY paper-research suite and the frozen legacy/statistical acceptance gates.

Important invariants include:

- paper/shadow only;
- 13 active independent strategies, not 15;
- no accidental risk-rule changes;
- no legacy-regression drift;
- no causal-data-quality regression.

## Data dependencies

D01 depends on NIFTY paper-research data under the `chartink-paper` runtime boundary, including:

- recorder SQLite/session data;
- live multi-shadow state;
- signal/trade state;
- generated reports;
- forward evidence packets.

The raw NIFTY data tree is protected by service-user permissions. The latest audit established that `/var/lib/chartink-paper` is mode `0700`, owned by `chartink-paper`; a non-privileged `ubuntu` inventory cannot be treated as a complete raw-data inventory.

## Serving dependency shared with D02

D01 and D02 share:

- Cloudflare Quick Tunnel;
- port `8765`;
- `mcx_paper.control_server`;
- report-serving directory.

They do **not** share strategy/generator ownership.
