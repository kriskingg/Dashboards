### Important nuance

The runtime executes files from the top-level deployed `analysis/` directory, but that directory is currently untracked in the server checkout. The corresponding authoritative Git-tracked files live under `nifty-options-paper-research/analysis/nifty_multi_shadow/`.

The runtime and GitHub blob hashes matched exactly at verification time, proving that the deployed copies were byte-for-byte identical to the authoritative source at that moment.

### Shared-serving boundary

The NIFTY HTML is generated by the NIFTY multi-shadow runtime, but the page is currently served by `mcx_paper.control_server` from the separate `/opt/chartink-paper/mcx-paper-research` deployment tree.

Therefore:

```text
NIFTY generator != HTTP/control server owner
```

Do not treat the common Cloudflare hostname or common port 8765 as evidence that the NIFTY and MCX applications share the same generator/code owner.

### Source-ownership conclusion

The MCX dashboard is generated by `kriskingg/hedge-engine`, not by the NIFTY multi-shadow generator.

The source deployment contract explicitly runs:

```text
python -m hedge_engine.runtime.paper_loop
```

and publishes:

```text
/var/lib/chartink-paper/nifty-multi-shadow/reports/mcx_latest.html
```

The runtime's default configuration contains the same published path and maintains its primary report under:

```text
/var/lib/hedge-engine/reports/mcx_latest.html
```

The migration runbook in `kriskingg/hedge-engine` explicitly documents the public page at `/mcx_latest.html` and states that the NIFTY `/live_latest.html` runtime is a separate boundary.

### Shared-serving boundary

```text
Cloudflare quick tunnel
        |
        v
127.0.0.1:8765
        |
        v
shared HTTP/control service
        |
        v
/var/lib/chartink-paper/nifty-multi-shadow/reports
        |
        +--> live_latest.html  -> NIFTY generator: etf-invest-engine
        |
        +--> mcx_latest.html   -> MCX generator: hedge-engine
```

A common hostname, port, HTTP server, or report directory does not imply common generator ownership.

### Fresh OCI verification result

The 2026-09-19 server audit proved all Git-tracked `/opt/hedge-engine` files byte-identical to deployed HEAD `e10eeeda...`, and GitHub `main` is at the same SHA. The primary and published `mcx_latest.html` copies were byte-identical when compared.

The installed `/etc/systemd/system/hedge-engine-paper.service` differs from the repository copy only because the installed file uses CRLF line endings while the repository uses LF. The logical unit configuration is identical.

See [D02-mcx-silver-hedge.md](D02-mcx-silver-hedge.md) and [SERVER1_RUNTIME_VERIFICATION_2026-09-19.md](SERVER1_RUNTIME_VERIFICATION_2026-09-19.md).
